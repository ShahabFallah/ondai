## Install

```bash
npx ondai add summarize
```

## Usage

```tsx
import { Summarize } from '@/components/ondai/summarize'

<Summarize text={thread.text} presentation="card" length="bullets" style="plain" />
```

- Short input streams in one pass; long input is chunked, summarized per chunk and reduced (progress shown).
- `useSummarize()` exposes the same logic headlessly.

## Variants

| Prop | Options |
| --- | --- |
| `presentation` | `card`, `inline`, `sheet`, `tooltip` |
| `length` | `oneLine`, `bullets`, `paragraph` |
| `style` | `plain`, `quote`, `highlighted` |

Every variant is live in the [playground](/playground/summarize).

## Token budget

Input budget: **3400 tokens**. Single streamed pass when the text fits; otherwise map (bullets per chunk) then reduce (streamed).

## Fallback

When no provider is ready the component renders the unavailable state (`AvailabilityGate` copy) and, where a deterministic path exists, keeps working without the model.
