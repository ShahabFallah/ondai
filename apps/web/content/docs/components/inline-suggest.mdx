## Install

```npm
npx ondai add inline-suggest
```

## Usage

```tsx
import { InlineSuggest } from '@/components/ondai/inline-suggest'

<InlineSuggest context="A message to Priya about Friday’s dinner" value={text} onChangeText={setText} />
```

- The model runs only after a pause in typing, and a guess for older text is never shown.

## Customize

Every AI component takes the same look and customization props, so it fits your app rather than ours.

```tsx
<InlineSuggest
  variant="pop"
  tint="#FF5A5F"
  size="lg"
  radius={12}
  icons={{ accept: Search }}
  labels={{ placeholder: '…', accept: '…' }}
/>
```

| Prop | What it does |
| --- | --- |
| `variant` | The look of the whole component: `clean`, `minimal`, `glass`, `pop`, `candy`, `metal`, `shine` |
| `size` | `sm`, `md`, `lg`; type, rows, icons and keys scale together |
| `tint` | Any colour; the variant paints its keys, tiles and glow in it |
| `radius` | Corner radius of the container |
| `icons` | Replace any icon (a lucide component, an element, or `null` to hide it): `accept` |
| `labels` | Every visible and spoken string; defaults are exported as `inlineSuggestLabels`: `placeholder`, `accept`, `hintKeyboard`, `hintTouch`, `thinking`, `suggestion` |
| Slots | Draw a part yourself: `renderAccept`, `renderHint` |
| `styles` | Style any named part |

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `clean`, `minimal`, `glass`, `pop`, `candy`, `metal`, `shine` |
| `size` | `sm`, `md`, `lg` |

## Fallback

When no provider is ready the component renders the unavailable state (`AvailabilityGate` copy) and, where a deterministic path exists, keeps working without the model.
