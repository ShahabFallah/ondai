## Install

```npm
npx ondai add image-reveal
```

## Usage

```tsx
import { ImageReveal } from '@/components/ondai/image-reveal'

<ImageReveal source={{ uri }} width={320} height={220} mode="ascii" progress={busy ? 'auto' : 1} />
```

- `progress` is 0–1 from your own pipeline, or `"auto"` to loop while you wait. `mode="ascii"` suits scans and documents; `mosaic` suits pictures.
- ScanToData uses it while OCR and extraction run.
