## Install

```bash
npx ondai add agent-avatar
```

## Usage

```tsx
import { AgentAvatar } from '@/components/ondai/agent-avatar'

<AgentAvatar size={64} shape="blob" state={isThinking ? 'thinking' : 'idle'} interactive />
```

- States: `idle` (glances around and blinks), `thinking` (looks up with an orbiting light), `speaking` (mouth moves), `sleeping` (eyes closed, slow breathing).
- On web, `interactive` makes the eyes follow the pointer.

## Variants

| Prop | Options |
| --- | --- |
| `shape` | `blob`, `square`, `pill`, `drop` |
| `state` | `idle`, `thinking`, `speaking`, `sleeping` |
| `eyes` | `dots`, `ovals` |

Every variant is live in the [playground](/playground/agent-avatar).
