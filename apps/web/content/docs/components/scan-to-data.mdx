## Install

```npm
npx ondai add scan-to-data
```

## Usage

```tsx
import { ScanToData } from '@/components/ondai/scan-to-data'
import TextRecognition from '@react-native-ml-kit/text-recognition'

<ScanToData
  preset="receipt"
  ocr={async (img) => (await TextRecognition.recognize(img.uri)).text}
  onData={(receipt) => expenses.add(receipt)}
/>
```

- OCR runs on device through the `ocr` function you pass (ML Kit, Apple Vision). The model only sees text, which also keeps the request inside the 4K budget.
- Presets: `receipt`, `businessCard`, `event`; or `preset="custom"` with your own zod schema.

## Customize

Every AI component takes the same look and customization props, so it fits your app rather than ours.

```tsx
<ScanToData
  variant="pop"
  tint="#FF5A5F"
  size="lg"
  radius={12}
  icons={{ scan: Search, camera: null }}
  labels={{ subject: '…', scan: '…' }}
/>
```

| Prop | What it does |
| --- | --- |
| `variant` | The look of the whole component: `clean`, `minimal`, `glass`, `pop`, `candy`, `metal`, `shine` |
| `size` | `sm`, `md`, `lg`; type, rows, icons and keys scale together |
| `tint` | Any colour; the variant paints its keys, tiles and glow in it |
| `radius` | Corner radius of the container |
| `icons` | Replace any icon (a lucide component, an element, or `null` to hide it): `scan`, `camera`, `library`, `reading`, `finding`, `done`, `error`, `retake` |
| `labels` | Every visible and spoken string; defaults are exported as `scanToDataLabels`: `subject`, `scan`, `scanHint`, `takePhoto`, `choosePhoto`, `noOcr`, `reading`, `read`, `gotText`, `lines`, `finding`, `findingMany`, `andMore`, `found`, `foundOne`, `fromYour`, `check`, `scanAgain`, `use`, `retake`, `error`, `scanning`, `scanAnother` |
| Slots | Draw a part yourself: `renderEmpty`, `renderRow`, `renderResult`, `renderUse` |
| `styles` | Style any named part |

## Token budget

Input budget: **1500 tokens**. OCR text (not the image) goes to the model; fields refined deterministically.

## Fallback

When no provider is ready the component renders the unavailable state (`AvailabilityGate` copy) and, where a deterministic path exists, keeps working without the model.
