## Install

```npm
npx ondai add ask-page
```

## Usage

```tsx
import { AskPage } from '@/components/ondai/ask-page'

<AskPage
  text={article.body}
  pageTitle={article.title}
  suggestions={['When is rent due?', 'Can I have a cat?']}
  onJump={(quote) => scrollToOffset(quote.start, quote.end)}
>
  <Article />
</AskPage>
```

- The answer comes from `text` only. The model also returns short quotes, and each one is checked against the page: an exact match (ignoring case and spacing) is kept with its `start` and `end` offsets, a paraphrase is matched to the closest sentence, and anything that is not in the page is dropped.
- Tapping a quote calls `onJump(quote, index)`, so the app can scroll to the passage and highlight it.
- When the page does not hold the answer, the model says `NOT_IN_PAGE` and the component shows **Not in this page** rather than a guess, with your starter questions to try instead.
- Follow-up questions come back with the answer; tapping one asks it.
- `useAskPage()` exposes the same logic headlessly; `parseAnswer`, `locateQuote` and `excerptForQuestion` are exported too.

## States

`idle`, `thinking`, `streaming`, `done`, `notFound`, `error`, `refusal`, `unavailable`, `preparing`.

## Customize

Every AI component takes the same look and customization props, so it fits your app rather than ours.

```tsx
<AskPage
  text={page}
  variant="pop"
  tint="#FF5A5F"
  size="lg"
  radius={12}
  quoteStyle="rule"
  icons={{ title: BookOpenText, followUp: null }}
  labels={{ title: '…', notFoundTitle: '…' }}
/>
```

| Prop | What it does |
| --- | --- |
| `variant` | The look of the whole component: `clean`, `minimal`, `glass`, `pop`, `candy`, `metal`, `shine`, `bevel` |
| `size` | `sm`, `md`, `lg`; type, field, quotes and keys scale together |
| `tint` | Any colour; the variant paints its keys, tiles, quote marks and glow in it |
| `radius` | Corner radius of the container |
| `icons` | Replace any icon (a lucide component, an element, or `null` to hide it): `title`, `send`, `stop`, `quote`, `jump`, `followUp`, `notFound`, `retry` |
| `labels` | Every visible and spoken string; defaults are exported as `askPageLabels`: `title`, `placeholder`, `idle`, `suggested`, `thinking`, `quotes`, `jump`, `followUps`, `notFoundTitle`, `notFoundHint`, `trimmed`, `retry`, `preparing`, `send`, `stop`, `inputLabel` |
| Slots | Draw a part yourself: `renderQuote`, `renderFollowUp`, `renderAnswer`, `renderEmpty`, `renderNotFound`, `renderError` |
| `styles` | Style any named part |

## Token budget

Input budget: **3400 tokens**. The whole page goes in one streamed pass when it fits; otherwise the chunks that best match the question are sent, in page order, and a quiet note says so. Quotes are always checked against the full page.

## Fallback

When no provider is ready the component renders the unavailable state (`AvailabilityGate` copy) and the field is disabled; while a model downloads it shows the progress.
