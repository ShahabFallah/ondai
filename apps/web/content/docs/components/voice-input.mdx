## Install

```npm
npx ondai add voice-input
```

## Usage

```tsx
import { VoiceInput, type Recorder } from '@/components/ondai/voice-input'

// Audio capture is yours to provide (expo-audio, react-native-audio-record, your own module).
const recorder: Recorder = {
  start: () => audio.start(),
  stop: () => audio.stop(), // resolves WAV/PCM bytes
  onLevel: (cb) => audio.subscribeLevel(cb),
}

<VoiceInput recorder={recorder} presentation="pill" visual="bars" onTranscript={(text) => setQuery(text)} />
```

- Transcription runs on device through `useTranscribe` (Apple SpeechAnalyzer on iOS 26). Without a `recorder` a simulated one runs, so the mock and the playground work out of the box.
- `mode="hold"` is push-to-talk; `mode="tap"` toggles. `visual` is `bars` (a rippling waveform) or `glow` (a bloom rising from the bottom edge).

## Customize

Every AI component takes the same look and customization props, so it fits your app rather than ours.

```tsx
<VoiceInput
  variant="pop"
  tint="#FF5A5F"
  size="lg"
  radius={12}
  icons={{ mic: Search, stop: null }}
  labels={{ holdHint: '…', tapHint: '…' }}
/>
```

| Prop | What it does |
| --- | --- |
| `variant` | The look of the whole component: `clean`, `minimal`, `glass`, `pop`, `candy`, `metal`, `shine` |
| `size` | `sm`, `md`, `lg`; type, rows, icons and keys scale together |
| `tint` | Any colour; the variant paints its keys, tiles and glow in it |
| `radius` | Corner radius of the container |
| `icons` | Replace any icon (a lucide component, an element, or `null` to hide it): `mic`, `stop`, `unavailable`, `retry`, `use` |
| `labels` | Every visible and spoken string; defaults are exported as `voiceInputLabels`: `holdHint`, `tapHint`, `listening`, `transcribing`, `releaseToStop`, `tapToStop`, `prompt`, `voice`, `transcript`, `use`, `retry`, `unavailable`, `error`, `start`, `stop`, `holding`, `unavailableKey` |
| Slots | Draw a part yourself: `renderMic`, `renderTranscript`, `renderActions` |
| `styles` | Style any named part |
