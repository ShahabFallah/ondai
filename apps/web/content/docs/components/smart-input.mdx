## Install

```bash
npx ondai add smart-input
```

## Usage

```tsx
import { SmartInput } from '@/components/ondai/smart-input'
import { z } from 'zod'

const expense = z.object({
  merchant: z.string(),
  amount: z.number(),
  category: z.enum(['food', 'transport', 'home', 'other']),
  date: z.string().describe('date').optional(),
})

<SmartInput schema={expense} presentation="field" onFill={(values) => form.reset(values)} aliases={{ category: { food: ['lunch', 'dinner'] } }} />
```

- Enums are fuzzy-matched, numbers and money parsed, dates resolved from phrases ("yesterday") in code after the model answers.
- Per-field confidence drives highlight / badge / underline styles and confirm/undo.
- For react-hook-form: `form.apply((name, value) => setValue(name, value))`.

## Token budget

Input budget: **1500 tokens**. One structured call; enum/number/date fields are refined deterministically after parsing.

## Fallback

When no provider is ready the component renders the unavailable state (`AvailabilityGate` copy) and, where a deterministic path exists, keeps working without the model.
