## Install

```bash
npx ondai add tool-confirm-card
```

## Usage

```tsx
import { ToolConfirmCard } from '@/components/ondai/tool-confirm-card'

const agent = useToolAgent({ tools, meta: { sendEmail: { policy: 'ask', risk: 'high' } } })

<ToolConfirmCard pending={agent.pendingConfirmation} presentation="card" />
```

- Works with provider-executed tool loops (Apple, Nano) because approval happens inside the tool's execute.

## Fallback

When no provider is ready the component renders the unavailable state (`AvailabilityGate` copy) and, where a deterministic path exists, keeps working without the model.
