title: "AvailabilityGate"
description: "Renders children only when the on-device model is ready; otherwise a quiet empty state with a way to turn it on."
---

<ComponentPreview name="availability-gate" state="not-eligible" height={300} />

## Install

```npm
npx ondai add availability-gate
```

## Usage

```tsx
import { AvailabilityGate } from '@/components/ondai/availability-gate'

<AvailabilityGate capability="text" variant="card">
  <YourAiFeature />
</AvailabilityGate>
```

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `card`, `inline`, `fullscreen` |

## Fallback

When no provider is ready the component renders the unavailable state (`AvailabilityGate` copy) and, where a deterministic path exists, keeps working without the model.
