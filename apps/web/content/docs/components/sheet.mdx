<ComponentPreview name="sheet" state="open" height={560} />

## Install

```npm
npx ondai add sheet
```

## Usage

```tsx
import { Sheet } from '@/components/ondai/sheet'

<Sheet open={open} onClose={close} presentation="sheet" variant="glass">…</Sheet>
```

## Variants

| Prop | Options |
| --- | --- |
| `presentation` | `sheet`, `spotlight`, `fullscreen` |
| `variant` | `glass`, `solid` |

## Fallback

Pure UI: no model required.
