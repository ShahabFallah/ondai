<ComponentPreview name="surface" state="" height={200} />

## Install

```npm
npx ondai add surface
```

## Usage

```tsx
import { Surface } from '@/components/ondai/surface'

<Surface elevation="card" style={{ padding: 16 }}>
  <Text>Follows the theme: solid, glass, or Liquid Glass on iOS 26</Text>
</Surface>
```

## Variants

| Prop | Options |
| --- | --- |
| `material` | `auto`, `solid`, `glass`, `native` |
| `elevation` | `inset`, `card`, `floating` |
| `skin` | `clean`, `minimal`, `glass`, `pop`, `candy`, `metal`, `shine` |

## Fallback

Pure UI: no model required.
