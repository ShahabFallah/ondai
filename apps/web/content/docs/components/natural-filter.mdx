## Install

```bash
npx ondai add natural-filter
```

## Usage

```tsx
import { NaturalFilter } from '@/components/ondai/natural-filter'
import { z } from 'zod'

const filters = z.object({ cuisine: z.enum(['italian', 'japanese']).optional(), price: z.enum(['$', '$$', '$$$']).optional(), openNow: z.boolean().optional() })

<NaturalFilter schema={filters} presentation="bar" onChange={(f) => setFilter(f)}>
  <RestaurantList filter={filter} />
</NaturalFilter>
```

- Chips are editable (tap an enum chip to cycle values) and removable.

## Token budget

Input budget: **600 tokens**. One structured call; enums, numbers and booleans refined deterministically.

## Fallback

When no provider is ready the component renders the unavailable state (`AvailabilityGate` copy) and, where a deterministic path exists, keeps working without the model.
