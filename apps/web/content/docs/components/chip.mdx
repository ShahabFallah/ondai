## Install

```npm
npx ondai add chip
```

## Usage

```tsx
import { Chip } from '@/components/ondai/chip'

<Chip label="Groceries" selected onPress={toggle} />
```

## Variants

| Prop | Options |

| `size` | `sm`, `md` |
| `skin` | `clean`, `minimal`, `glass`, `pop`, `candy`, `metal`, `shine` |
