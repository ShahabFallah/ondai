## Install

```bash
npx ondai add chip
```

## Usage

```tsx
import { Chip } from '@/components/ondai/chip'

<Chip label="Groceries" selected onPress={toggle} />
```

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `soft`, `outline`, `solid`, `ghost` |
| `size` | `sm`, `md` |

Every variant is live in the [playground](/playground/chip).
