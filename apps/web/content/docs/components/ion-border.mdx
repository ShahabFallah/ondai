## Install

```bash
npx ondai add ion-border
```

## Usage

```tsx
import { IonBorder } from '@/components/ondai/ion-border'

<IonBorder active={isThinking} variant="beam" radius="lg" glow>
  <YourCard />
</IonBorder>
```

- `variant`: `sweep` (the slow gradient light), `beam` (a bright comet with a tail and an outer halo), `pulse` (the whole ring breathes).

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `sweep`, `beam`, `pulse` |
| `radius` | `none`, `sm`, `md`, `lg`, `xl`, `pill` |

Every variant is live in the [playground](/playground/ion-border).
