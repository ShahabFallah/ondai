## Install

```bash
npx ondai add thinking-indicator
```

## Usage

```tsx
import { ThinkingIndicator } from '@/components/ondai/thinking-indicator'

<ThinkingIndicator variant="dots" label="Thinking" />
```

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `dots`, `orb`, `line`, `sweep` |
| `size` | `sm`, `md`, `lg` |

Every variant is live in the [playground](/playground/thinking-indicator).
