## Install

```npm
npx ondai add thinking-indicator
```

## Usage

```tsx
import { ThinkingIndicator } from '@/components/ondai/thinking-indicator'

<ThinkingIndicator variant="orb" size="lg" state="thinking" label="Thinking" />
```

- The `orb` is a metallic sphere with a drifting highlight; `state` (`thinking`, `listening`, `speaking`) changes its rhythm.

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `shimmer`, `dots`, `orb`, `line`, `sweep` |
| `size` | `sm`, `md`, `lg` |
| `state` | `thinking`, `listening`, `speaking` |

## Fallback

Pure UI: no model required.
