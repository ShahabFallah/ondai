## Install

```bash
npx ondai add field
```

## Usage

```tsx
import { Field } from '@/components/ondai/field'

<Field label="Merchant" value={v} onChangeText={setV} state={status} confidence={0.9} />
```

## Variants

| Prop | Options |
| --- | --- |
| `size` | `md`, `lg` |
| `confidenceStyle` | `highlight`, `badge`, `underline`, `none` |
