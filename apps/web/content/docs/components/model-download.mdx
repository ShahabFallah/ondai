<ComponentPreview name="model-download" state="preparing" height={200} />

## Install

```bash
npx ondai add model-download
```

## Usage

```tsx
import { ModelDownload } from '@/components/ondai/model-download'

<ModelDownload progress={0.42} variant="bar" label="Preparing model" detail="1.2 GB · Wi-Fi only" />
```

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `bar`, `ring`, `card` |
| `size` | `sm`, `md`, `lg` |

Every variant is live in the [playground](/playground/model-download).
