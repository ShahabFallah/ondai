## Install

```npm
npx ondai add liquid-metal
```

## Usage

```tsx
import { LiquidMetal } from '@/components/ondai/liquid-metal'

<LiquidMetal active={isListening} shape="circle">
  <MicButton />
</LiquidMetal>
```

- libraries.dev’s metal-fx (MIT); the material is Paper Shaders’ liquidMetal (Apache-2.0, NOTICE included).
- Needs `@shopify/react-native-skia` (included in Expo Go).

## Variants

| Prop | Options |
| --- | --- |
| `shape` | `button`, `circle` |
| `preset` | `chromatic`, `silver`, `gold` |

## Fallback

Pure UI: no model required.

No model-driven fixtures for this component.
