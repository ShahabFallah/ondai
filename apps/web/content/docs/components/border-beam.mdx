## Install

```npm
npx ondai add border-beam
```

## Usage

```tsx
import { BorderBeam } from '@/components/ondai/border-beam'

<BorderBeam active={isThinking} radius="lg">
  <Card />
</BorderBeam>
```

- libraries.dev’s border beam (MIT, Jakub Antalik): a Skia shader on iOS and Android, its CSS version on web.
- Needs `@shopify/react-native-skia` (included in Expo Go).

## Variants

| Prop | Options |
| --- | --- |
| `tone` | `mono`, `colorful`, `ocean`, `sunset` |
| `size` | `md`, `sm`, `line`, `pulse-inner`, `pulse-outside` |
