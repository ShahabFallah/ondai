<ComponentPreview name="button" state="idle" height={160} />

## Install

```npm
npx ondai add button
```

## Usage

```tsx
import { Button } from '@/components/ondai/button'

<Button title="Summarize" variant="solid" onPress={run} />
```

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `solid`, `raised`, `soft`, `outline`, `ghost`, `accent`, `danger` |
| `size` | `sm`, `md`, `lg` |
| `skin` | `clean`, `minimal`, `glass`, `pop`, `candy`, `metal`, `shine` |
