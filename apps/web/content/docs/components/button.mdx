## Install

```bash
npx ondai add button
```

## Usage

```tsx
import { Button } from '@/components/ondai/button'

<Button title="Summarize" variant="solid" onPress={run} />
```

## Variants

| Prop | Options |
| --- | --- |
| `variant` | `solid`, `soft`, `outline`, `ghost`, `accent`, `danger` |
| `size` | `sm`, `md`, `lg` |

Every variant is live in the [playground](/playground/button).
