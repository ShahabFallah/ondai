## Install

```npm
npx ondai add bot-avatar
```

## Usage

```tsx
import { BotAvatar } from '@/components/ondai/bot-avatar'

<BotAvatar state={isWorking ? 'working' : 'default'} size={64} />
```

- libraries.dev’s bot avatars (MIT): 18 bodies plus Ondai’s chrome chip.
- Needs `@shopify/react-native-skia` (included in Expo Go).

## Variants

| Prop | Options |
| --- | --- |
| `type` | `chip`, `clover`, `blob`, `square`, `pill`, `drop`, `ghost`, `droid` |
| `state` | `default`, `working`, `sleeping` |

## Fallback

Pure UI: no model required.
