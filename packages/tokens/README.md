# @ondai/tokens

Design tokens for Ondai: Void / Paper / Glass themes, accent presets (ion, mono, aurora, ember, custom), type scale, 4pt spacing, radii, elevation and motion springs.

```ts
import { resolveTheme } from '@ondai/tokens'
import { ThemeProvider, useTheme } from '@ondai/tokens/react'
```

Also ships a Tailwind preset (`@ondai/tokens/tailwind-preset`) and CSS variables (`@ondai/tokens/css`) so NativeWind / react-native-reusables apps and the website share one palette.
