# IonBorder

The signature thinking border: a slow gradient light travels around any container while the AI works.

```bash
npx ondai add ion-border
```

```tsx
import { IonBorder } from '@/components/ondai/ion-border'

<IonBorder active={isThinking} radius="lg" glow>
  <YourCard />
</IonBorder>
```

Docs: https://ondai.dev/docs/components/ion-border
