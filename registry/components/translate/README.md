# Translate

Live translation on device: the original, a row of target languages, the translation streaming in, with copy and an instant swap.

```bash
npx ondai add translate
```

```tsx
import { Translate } from '@/components/ondai/translate'

<Translate text={message.text} from="en" to="it" />
```

Docs: https://ondai.dev/docs/components/translate
