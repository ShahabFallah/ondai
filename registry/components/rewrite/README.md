# Rewrite

Shorten, expand, friendlier, formal or fix grammar, streamed on device, with replace / diff / side-by-side results and accept/reject.

```bash
npx ondai add rewrite
```

```tsx
import { Rewrite } from '@/components/ondai/rewrite'

<Rewrite value={draft} onAccept={setDraft} presentation="toolbar" resultView="diff" />
```

Docs: https://ondai.dev/docs/components/rewrite
